# spermotroll_db

Статический сайт: дни рождения + пункты выдачи WB и Ozon.
Тёмная анонимус-тема, без сборки.

## Запуск

Открой `index.html` в браузере. Или закинь папку на GitHub Pages / Netlify.

## Правка данных

Всё в `data.js`. Один массив `TROLLS`:

- name - имя
- birthday - "ДД.ММ.ГГГГ"
- wb - адрес WB или пустая строка
- ozon - адрес Ozon или пустая строка
